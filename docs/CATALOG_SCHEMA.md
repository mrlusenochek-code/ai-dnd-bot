# Catalog Schema

Классы и расы приводятся к единому каноническому каркасу при загрузке base + private каталогов.

## RaceDef
- `key`: уникальный ключ расы.
- `name_ru`: отображаемое название.
- `description_ru`: краткое описание/лор.
- `asi`: структурные бонусы характеристик.
- `age`: структура возраста (`adult`/`max`/`notes` и т.п.).
- `alignment`: заметки по мировоззрению.
- `size`: `small | medium | large`.
- `speed_ft`: базовая скорость.
- `speed_notes_ru`: примечания к скорости.
- `languages`: канонические ключи языков.
- `traits`: трейты `[{key, name_ru, text_ru, mechanics}]`.
- `subraces`: подрасы/варианты.
- `source`: источник данных (`PHB`, `EXT`, ...).
- `tags`: служебные теги.

## ClassDef
- `key`: уникальный ключ класса.
- `name_ru`: отображаемое название.
- `description_ru`: краткое описание/лор.
- `hit_die`: кость хитов.
- `primary_abilities`: ключевые характеристики (`str/dex/con/int/wis/cha`).
- `saving_throws`: спасброски класса.
- `proficiencies`: владения (броня/оружие/инструменты).
- `skill_choices`: структура выбора навыков.
- `starting_equipment`: стартовое снаряжение.
- `features_by_level`: фичи по уровням (`1..20`).
- `subclasses`: подклассы.
- `spellcasting`: схема кастера (заглушка под развитие).
- `spell_lists`: списки заклинаний (заглушка под развитие).
- `source`: источник данных.
- `tags`: служебные теги.

## Notes
- Сейчас часть полей заполняется пустыми значениями по умолчанию.
- Это ожидаемо: каркас введён для постепенного PHB-наполнения в следующих итерациях.
